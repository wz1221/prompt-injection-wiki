# Prompt Injection 與 LLM Agent 安全 — LLM Wiki

課堂作業：用 LLM Wiki 做一份教學 HTML 簡報。

## 這是什麼？
一套給一般大眾閱讀的知識庫，說明「提示注入（Prompt Injection）」是什麼、為什麼 AI 助理會被藏在網頁或信件裡的指令影響，以及目前有哪些防禦方式與限制。最後以這套 Wiki 為知識來源，製作一份 HTML 教學簡報。

## 線上瀏覽

- 教學簡報（可直接瀏覽）：開啟本儲存庫 GitHub Pages 網址後加上 `/presentation/index.html`
- Wiki 首頁：[wiki/index.md](wiki/index.md)
